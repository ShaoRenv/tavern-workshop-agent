4. **期望**：按钮变「打包中…」并出现进度条（完成数 / 总数）；结束后出现结果统计与输出预览，并提供「**复制 JSON**」（点后变「已复制」）与「**下载 JSON**」；失败会给出失败角色列表 / 日志，好角色仍保留。
5. **失败判据**：
   - 按钮一直灰 → 没有可打包角色（N=0）。
   - 报连接错误 → 酒馆 API 未配好或模型不可用。
   - 输出 JSON 解析失败 → 换「元数据规则 / 模板」或降低批大小 / 温度重试。
   - 中途卡住 → 点「**中止**」，已完成角色不丢（引擎支持断点续跑）。

### C6. 页签③「世界书」—— 载入源世界书、勾势力、生成、创建新世界书

1. 点页签 `③ 世界书`。
2. 「**源世界书**」下拉 → 选「**我的苍玄界，才不会这么跌宕起伏！**」（没有就点「**刷新列表**」；读取失败时页面给红色错误并打控制台 `[苍玄界立绘工坊] 读取世界书列表失败`）。
3. 点「**载入世界书**」。**期望**：
   - 左侧「按区块勾选」出现区块（如「角色设定（N）」），每行有「全选 / 取消」；
   - 右侧「按势力勾选」出现形如 `[上三宗] 天剑宗（M）` 的条目（真实数据 18 个势力）；若源世界书没有「势力概览」条目，右侧提示「未解析到势力树（该世界书可能没有「势力概览」条目）。」
4. 找到「**天剑宗**」，点它左边的「**选**」。**期望**：按钮文案「开始生成（已选 X 个角色）」中的 X **增加**，增加量 = 天剑宗括号里的 M；左表勾选状态同步。
5. 点「**开始生成（已选 X 个角色）**」（「世界书预设」下拉可先保持内置默认，默认含「全角色蓝灯精简」策略）。
6. **期望**：出现进度条「进度 completed / total」；结束后出现「生成结果」区（字数统计 + 可编辑文本框 + 「下载 txt」）。
7. 点「**创建新世界书**」（按钮上方先显示「将创建：<名字>」）。**期望**：按钮变「创建中…」，成功后页面出现绿色一行「**已创建世界书「<名字>」。**」，并且酒馆的「世界书」列表里能看到新名字。
   - 命名规则（源码 `resolveWorldbookName`）：默认模板 `{源名} · 全角色蓝灯精简`；**同名已存在时自动加序号后缀** `(2)`、`(3)`…（若预设的冲突策略选「时间戳」则追加时间戳）。所以「带序号后缀」= 该名字被占用过的正常表现。
8. **失败判据**：
   - 「创建新世界书」一直灰 → `worldbookText` 为空（还没生成）或正在创建。
   - 创建后世界书列表没有新名字 → 看控制台异常；确认当前账号有创建权限。
   - 势力区为空但你确信有「势力概览」→ 把世界书名反馈给我，属解析器边界（单测已覆盖缩进子块与错位区块两种形态，真实数据可能还有第三种）。

### C7. 页签④「预设与模板」—— 改字段 + 刷新后仍在

1. 点页签 `④ 预设与模板`。**期望**：出现子页签（LLM 预设 / 模板 / 元数据规则 / 世界书预设）。
2. 在「LLM 预设」里选中一个预设，改一个字段，例如把「**温度**」改成 `1.1`，或把「名称」改一个字。
3. **等约 1 秒**（保存有防抖），然后**刷新页面**（酒馆按 F5，或重新渲染该楼层）。
4. 重新打开界面 → 页签④。**期望**：刚才改的值**仍是 `1.1`**。
5. **失败判据**：
   - 值回到默认 → 持久化没生效；看控制台是否有 `[苍玄界立绘工坊] 保存数据失败`（数据写全局变量，键 `cx_portrait_workshop_v1`）；
   - 若始终不保存 → 确认当前环境允许写全局变量、且已打开聊天；
   - 内置预设不可删（`builtin`），但字段可改。

### C8. 出问题时怎么快速定位

1. 按 **F12** 打开控制台。界面自带日志前缀 **`[苍玄界立绘工坊]`**（当前代码只有两处告警：`保存数据失败`、`读取世界书列表失败`）；**没有该前缀**的报错通常是环境层（酒馆助手注入 / CDN 加载）。
2. iframe 调试不便时：酒馆助手「渲染」设置里打开「**使用 Blob URL 渲染前端界面**」，iframe 有独立 URL，可在 DevTools 里选中该 frame 看日志。
3. 症状速查：
   - 白屏 + 无任何日志 → CDN 不可达 / 酒馆助手未注入 Vue；
   - 界面出得来但采集为空 → 缺「状态栏」脚本（C0）；
   - 解析全失败 → 网络或图床跨域，改用代理前缀或手动上传；
   - 试跑失败 → 酒馆 API / 模型问题（`generateRaw` 走当前连接）。
