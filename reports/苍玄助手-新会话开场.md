## 9. 已知坑（都踩过）

- 相对 import **必须带扩展名**（`.ts` / `.vue`）；
- **一个脚本 = 一个文件**：`import()` 拆出的 chunk 在单文件酒馆脚本里永远 404 → 插件页面**必须静态 import**，`limitChunkCount = 1`，门禁查 chunk 数；
- `npx tsc --noEmit` **不查 .vue** → 想抓 .vue 错误只能靠 `pnpm build`；
- 真酒馆看效果的前提：脚本库里必须有「苍玄助手（开发版）」那条，否则 dev server 推了也没有 iframe 去加载 `/panel.js`；脚本库被别的客户端冲掉过，可用 `TavernHelper.updateScriptTreesWith(l => l.concat([devScript]), { type: "global" })` 装回；动酒馆环境前先备份 `settings.json`；
- `store.save()` 有 2500ms debounce → 断言前先 `store.save(true)`；
- `tavern_sync.mjs` / pnpm 偶发**假 exit 1** → 用 `$LASTEXITCODE` 复核；
- 页 id 解析有两处：`TAB_ID_ALIASES`（schema 层）和 `store.setTab`；**绝不把不可用的页 id 写进 `active_tab`**；
- 中间路线备忘（计划外）：生产也可走「1KB 引导脚本 + 远程代码/资源」（开发版已是此模式）—— 零迁移、接口全在，但占脚本库、依赖托管在线。排序：扩展 > 引导脚本 > 现状。
