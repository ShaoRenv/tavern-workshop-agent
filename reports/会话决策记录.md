## 2. 立绘工具的确切形状（D6 + 用户 C4 回答）

用户原话：「c4 返回提示词，不要元数据，多个，我给过你提示词的 JSON 键」

### 工具形状

```
portrait_list              → 列出角色（名字 + 有没有图 + 来源）
portrait_prompt(names[])   → 批量读原生图提示词（支持一次多个名字）
```

- `portrait_meta` **删掉**（用户明确说「不要元数据」）
- `names[]` **支持多个**（批量提取）
- 只返回**提示词**，不返回元数据

### 「固定格式人物预设提示词」的 JSON 键（用户指的就是这个）

来源：`src/苍玄助手/presets/builtin.ts` 的 `ZHI_SKELETON`（智绘姬预设骨架）。
链路：`portrait_prompt` 读出 `char_caption`（角色DNA）+ `prompt`（完整提示词）
→ **LLM 转换**成下面这套键 → `write_file` 落盘。

```json
{
  "characters": {
    "[苍玄界]<中文名>": {
      "nameCN": "<中文名>",
      "nameEN": "<全小写拼音，空格分隔>",
      "characterTraits": "<2-5 个英文标签>",
      "facialFeatures": "<面部与发型>",
      "facialFeaturesBack": "<背面发型>",
      "upperBodySFW": "<上身>",
      "upperBodySFWBack": "<背面>",
      "fullBodySFW": "<下身>",
      "fullBodySFWBack": "<背面>",
      "upperBodyNSFW": "",
      "upperBodyNSFWBack": "",
      "fullBodyNSFW": "",
      "fullBodyNSFWBack": "",
      "outfits": ["[苍玄界]<服装名>"],
      "negative": "<角色负向词>",
      "generationContext": "",
      "generationVariables": {},
      "generationWorldBook": "",
      "mediaSchemaVersion": 2
    }
  },
  "outfits": {
    "[苍玄界]<服装名>": {
      "nameCN": "<服装名>",
      "nameEN": "<服装英文>",
      "owner": "<该角色的 nameEN>",
      "upperBody": "",
      "upperBodyBack": "",
      "fullBody": "",
      "fullBodyBack": ""
    }
  }
}
```

### 转换规则（智绘姬预设里已有的 `ZHI_RULES`，原文）

- 角色按身体部位拆成六个字段：facialFeatures / facialFeaturesBack / upperBodySFW / upperBodySFWBack / fullBodySFW / fullBodySFWBack。
- 背面字段若无法从正面立绘得知，可依据已有特征合理推断，不要留空。
- nameEN 必须是小写、以单个空格分隔的拼音；它同时是 outfits 中 owner 的取值。
- outfits 数组填服装键名，键名必须是 [苍玄界]<中文服装名>；服装条目另起一张表。
- 保留原始 NovelAI 权重语法（如 1.6::xxx::），不要转换成其他语法。
- 无法从 SFW 立绘推断的 NSFW 字段留空字符串，禁止编造。

### 智绘姬系统提示词（原文，`ZHI_SYSTEM`）

```
你要把一张立绘的元数据转换成「智绘姬」角色预设。

输入里的「角色DNA（char_caption）」是该角色最可靠的外观描述，请以它为准；
「完整提示词（prompt）」里的场景、构图、光影、画风词**不属于角色本身**，不要写进角色字段。

请逐个角色转换，严格遵守下面的 JSON 结构，只输出 JSON，不要输出任何解释性文字。
```

### 已实测的世界书事实（真机验过，不是读文档）

- **order 越大越靠近最新消息**（`order=1` 排在 `order=999` 前面）
- **死条目**（非常亮 + 无关键词）任何消息都不激活
- `selective` 字段**不影响**激活判定；**次关键词是硬门槛**
- `matchWholeWords` 默认 **false**（TavernWeave 手册说默认开是错的）
- 当前环境 `world_info_depth` = **2**（不是手册说的 4；4 是 `DEFAULT_DEPTH`）
- ⚠️ **`worldInfoCache` 会缓存整本书**，改完磁盘再试算必须先 `worldInfoCache.delete(书名)`
