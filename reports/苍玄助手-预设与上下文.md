# 苍玄助手 · 预设 / 特殊层 / 能力启用（最终口径）

> 用户 2026-09-20 临睡前定的最终口径。**这份是权威版**，实现照它。

## 一、上下文：只做「特殊层」，不做宏

- **`{{上下文}}` 宏不要了。** 上下文只以**特殊层**形式存在，运行时**原生展开**成真正的多条对话消息（`role:'user'` / `role:'assistant'` / `role:'tool'`），按原角色插进消息序列。
- 理由（用户原话的意思）：纯文本上下文是给「文本化适配」准备的，那条路不走了 —— 我们就是要**原生格式**。
- 实现收尾时：`views/SettingsView.vue` 里那个 `{{上下文}}` 插入芯片删掉；`core/macros.ts` 的 `formatHistory()` 保留渲染能力做**兼容**（老预设万一用过不至于报错），但标注**弃用**，新预设不许用。

## 二、特殊层：只做 上下文 / 用户需求

- 预设编辑里一个 **「＋ 添加特殊层」** 按钮，第一版给：**上下文**、**用户需求（User）**
- 后续想加再加（界面留位置，不加占位 UI）
- **不要**把「世界书」「本次范围」「可用技能」做成特殊层 —— 用户明确否掉：**这是 agent，这些信息应该它自己用工具去看**（原话「它是 agent，这些信息应该它自己来看」）

### `{{用户需求}}` 宏保留
- 内置预设（立绘、世界书与条目）现在就在用 `{{用户需求}}`（`presets/builtin.ts:301,352`），**保留为纯文本宏**，不动

## 三、不做分割线装饰

用户给的 `══════ 【AI助手】 ══════` 那个样式**作废**（原话「你就当没听到」）—— 本来就是为纯文本上下文准备的。
UI 继续沿用现有的极简优雅风格，不加新装饰。

## 四、能力启用：全局 + 预设单独启用（两级）

| 层级 | 在哪 | 作用 |
|---|---|---|
| **全局** | 「能力」页（工具｜技能） | 工具/技能的**默认启用**，唯一全局开关 |
| **预设单独启用** | 预设里一个开关按钮 | 打开后：这个预设**只用自己勾的能力，完全不再用全局的工具与技能** |

- 原「这个预设用什么」→ 改名 **「单独启用预设能力」**，旁边写明「打开后不再使用全局工具及技能」
- **默认关**（用户确认）：新预设跟随全局

## 五、对话设置（对话页的按钮）

顶栏按钮 → Sheet，三件事：**切换聊天** / **切换预设** / **删除对话**。
（数据层 `deleteSession` 已有，含「删当前自动退到下一条」；这里只是把入口收到一处。）

## 六、预设合并（去 kind）

```
Preset {
  id, name,
  items: [ {type:'message', role, content} | {type:'special', kind:'context'|'user'} ],
  use_global_caps: boolean,          // 「单独启用预设能力」：false = 跟随全局（默认）
  tools: string[], skills: string[], // 只在 use_global_caps = true 时生效
}
```
- **不再有 `kind`**：是不是 agent，由「有没有勾工具」决定
- 老数据 `DATA_VERSION 3 → 4` 幂等迁移：agent 预设 → `items=[{role:'system', content: system}]`；plain 预设 → `items = messages`；`use_global_caps = false`

## 七、为什么这样模型不会变傻（实现时的硬约束）

1. 能走**原生 function calling** 就走原生（自己填接口 = 原生；酒馆 `generateRaw` = 文本降级，是最大变量）
2. 形状：`system`(规矩) → `user`(任务) → `assistant.tool_calls` → `role:'tool'` → `assistant`…
3. 历史**原样搬**：不加 `【用户】` 前缀、不重命名角色（现在的 `formatHistory` 就是反例，只在兼容路径里留着）
4. system 里别写「这是本次对话的上下文」
5. 工具结果结构化 + 简短，超长明确写「已截断」
