## 3. LLM 相关怎么测（这块特殊）

LLM 输出不确定，不能像纯函数那样断言。我的做法：

| 手段 | 做法 |
|---|---|
| **契约测试** | 不测「LLM 说了什么」，只测「拿到的 JSON 是否符合 zod schema」—— 这是确定性的 |
| **录制回放** | 跑一次真实 LLM，把回复存成 fixture；之后回归测试用回放，不重复烧 token |
| **异常注入** | 人工构造残缺/多余/串味的 LLM 回复（带前言、多个 JSON、缺字段），验证提取+修复能扛住 |
| **小样本人工核验** | 挑 3 个角色（1 女 1 男 1 特殊），我人工看产出质量，贴给你确认 |

**建议**：第一版先只用 **2-3 个角色**跑通全链路，你确认格式对了，再放大到 170+。
避免一开始就烧大量 token 才发现格式要改。
