这一屏的规矩

  • 只有列表：图标 · 名字 · 状态 · 来源与版本 · 开关 · >。行与行完全同构，以后加什么插件都是这一行，不给出任何一个插件开小灶。
  • > 进这个插件的页面；行尾开关是快捷启停（进详情里也有同一个开关，改的是同一个值）。
  • 页面上不放别的：不放分工说明、不放「还没做」、不放某个插件的工具清单和生图预览——那些要么属于工具段，要么在对话页里自然出现。
  • 列表会长：插件多了就往下长，不加分组、不做折叠、不做内嵌滚动区。头上一行「5 个 · 启用 1」。
  • 下面 4 行是**示例**（用来验证列表长度与状态色），真做了才出现；状态色只有三档：未启用（灰）/ 缺配置（黄）/ 已启用（青）。

为什么这样切

  • 顺序 = 从常用到少见：采样方法 / 噪点表 / 步数 / 尺寸 / 种子 / 引导强度 / 张数上限，一块到底，不分子块、不加折叠。
  • 尺寸是预设 + 宽高联动：选预设改宽高，手改宽高预设变「自定义」，同一件事不填两遍。
  • 数值写清量纲与代价：步数标 1–50 并说「越慢越贵」；张数上限说明「这是钱的上限」。
  • Guidance Rescale 这类只有新模型认的，并进「高级」按版本显示（下一屏）。

这一屏的规矩

  • 只摆当前模型真认的开关：切 v3 才出现 SMEA / SMEA DYN / 减少伪影，切 v5 才出现透明背景。不摆点不动的死控件，不显示时补一句「为什么没有」。
  • 危险动作在最底、红描边、说清代价（含 API Key），并且要二次确认。
  • 整页没有「三栏网格」：一行一件事，手机上一路滚下去。

透明背景只有 v5 认。

这一版删掉了什么（按你的意见）
· 列表页的「分工说明 / 还没做 / 某个插件的工具清单」——全删
· 插件页的「能力链路 / 它提供哪些工具」——全删（工具在工具段，能不能用由能力与预设决定）
· 插件页的「试画 + 结果预览 / 一次几张以外的出图设置」——全删（出图在对话页显示）
· 状态变体不再单独占屏；状态就是列表行上那一个标签 + 详情里的一个开关
要你拍的问题
1 列表行要不要快捷开关？

现在设计是「行尾开关 + 行点进详情（开关同一个值）」。也可以只留 >，启停只在详情里做。

2 插件页的骨架认不认？

头部（返回 / 名字 / 来源版本 / 启用）+ 这个插件自己的设置块（生图＝接口 / 提示词 / 参数 / 高级）+ 底部恢复默认。

3 默认值

步数 28 / 832×1216 / Euler Ancestral / Guidance 5 / 一次最多 1 张。要不要照 st-chatu8（1024×1024 / k_euler / Guidance 10 / rescale 0.18）？
